Settings

On this page the the system can be configured. For the network settings there are two choices: Wifi or Ethernet. One can choose either one of them or both. If no interface is set (both off) or when ethernet is down, then an wifi AP will be launched. The hostname can be set in the Wifi section but is actually also used for the Ethernet interface and for the syslog messages. DNS servers are also set globally. The last interface to come up will set the DNS servers.
