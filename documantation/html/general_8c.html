Detailed Description

General utility functions for system initialization and runtime helpers.

This module provides NVS/LittleFS initialization, shared mutex creation, formatted date/time helpers, and file I/O utilities used across the firmware.

esp_err_t create_mutexes ( void )

Create global mutexes used by runtime configuration and tasks.

If any mutex creation fails, this function cleans up already-created mutexes to keep the system in a consistent state.

Returns
ESP_OK when all mutexes were created, ESP_FAIL otherwise.
