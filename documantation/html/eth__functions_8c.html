Detailed Description

Ethernet lifecycle and configuration support for W5500-based interfaces.

This module manages safe initialization, teardown, restart, and configuration of Ethernet hardware and the associated ESP-NETIF interface. It also provides helper functions for link status checks and DHCP/static IP application.
