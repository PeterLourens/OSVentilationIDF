Detailed Description

Runtime JSON configuration loading and parsing helpers.

This module reads embedded JSON files from LittleFS and updates the runtime configuration structures used by networking, sensors, fan control, MQTT, InfluxDB, syslog, I2C, and the state machine.

Read JSON state files under mount_point that match pattern, parse into statemachine_config[] (global) up to MAX_NR_STATES / max_files.

This supports JSON files whose root can be an object or an array of objects and loads them in order until the state array is full or the file limit is reached.

Parameters
