\doxysubsection{Detailed Description}
Public configuration loading and parsing interfaces. 

This header exposes the functions used to load JSON-\/backed configuration files for sensors, networking, MQTT, Influx\+DB, fan control, I2C, syslog, and the statemachine. It also provides flexible JSON helper functions for parsing booleans, integers, and state objects.
