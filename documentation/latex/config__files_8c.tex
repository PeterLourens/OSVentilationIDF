\doxysubsection{Detailed Description}
Runtime JSON configuration loading and parsing helpers. 

This module reads embedded JSON files from Little\+FS and updates the runtime configuration structures used by networking, sensors, fan control, MQTT, Influx\+DB, syslog, I2C, and the state machine.
