Detailed Description

Public Ethernet lifecycle and configuration API for the W5500 interface.

This header exposes the Ethernet initialization, restart, teardown, and configuration helpers used by the OSVentilation runtime. It also declares helpers for link status, connection state, and shutdown coordination.

esp_err_t eth_hardware_reset ( void )

Perform a guarded hardware reset of the Ethernet controller.

This function safely resets the W5500 and reinitializes the Ethernet stack, ensuring that no lifecycle races occur during the reset.

Returns
ESP_OK on success, otherwise an esp_err_t.

Perform a guarded hardware reset of the Ethernet controller.

This function acquires the Ethernet lifecycle mutex, stops DHCP and driver activity, toggles the W5500 reset GPIO if configured, and reinitializes the Ethernet stack. It ensures that no event handler races occur during reset.

Returns
ESP_OK on success, ESP_ERR_TIMEOUT if the lifecycle mutex could not be taken, or an ESP error code from initialization or driver start operations.

◆ eth_hardware_reset_safe()

esp_err_t eth_hardware_reset_safe ( void )

Safe reset helper: try software restart first, then guarded hardware reset.

This wrapper prefers a light-weight software restart (eth_software_restart). If that fails or does not restore link, it calls the guarded hardware reset (eth_hardware_reset) which toggles the W5500 reset GPIO and reinitializes.

Returns
ESP_OK on success, otherwise an esp_err_t describing the failure.
