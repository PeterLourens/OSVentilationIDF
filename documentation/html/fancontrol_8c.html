Detailed Description

Fan speed control implementation for HTTP and MQTT-driven fans.

This module reads fan control configuration from the shared fan_config structure and performs fan speed changes via HTTP GET requests or MQTT.

Set the configured fan speed via the selected control method.

Set the target fan speed using the configured fan control method.

The function reads the current fan control mode and endpoints from the runtime fan_config structure and applies the requested speed using HTTP or MQTT.
