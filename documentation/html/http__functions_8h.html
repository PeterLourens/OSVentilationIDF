esp_err_t http_server_start ( void )

Start the embedded HTTP server and bind handlers.

This function starts the HTTP server on port 80 and registers the web UI, WebSocket, and configuration endpoints.

Returns
ESP_OK if the server started successfully.
ESP_ERR_INVALID_STATE if the active network interface has no IP.
other esp_err_t values on HTTP server startup failure.

Start the embedded HTTP server and bind handlers.

Returns
ESP_OK on success, or an esp_err_t on failure.

◆ http_server_stop()

esp_err_t http_server_stop ( void )

Stop the embedded HTTP server and release resources.

This function stops the HTTP server instance and clears the global server handle so the server can be restarted later if needed.

Returns
ESP_OK if the server was stopped successfully.
ESP_ERR_INVALID_ARG if the server handle was not valid.
other esp_err_t values on shutdown failure.

Stop the embedded HTTP server and release resources.

Returns
ESP_OK on success or an esp_err_t on failure.
