void set_fanspeed ( int fanspeed)

Set the target fan speed using the configured fan control method.

The configured mode may be HTTP API or MQTT publish; the corresponding URL or MQTT topic is read from the fan configuration.

Parameters
fanspeedDesired fanspeed: 0=error/unset, 1=low, 2=medium, 3=high.

Set the target fan speed using the configured fan control method.

The function reads the current fan control mode and endpoints from the runtime fan_config structure and applies the requested speed using HTTP or MQTT.
